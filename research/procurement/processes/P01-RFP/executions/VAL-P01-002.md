## 3. Observed Behavior & Failure Analysis

1. **Test Procedure:**
   - Opened Agent Lab and initiated agent prompt configuration.
   - Selected "Configure Prompt" modal under the "Basic Config" tab.
   - Focused the "System instructions" textarea and continuously typed prompt rules and formatting instructions over a 30-second window.
2. **Observed Failure:**
   - While actively typing instructions, a periodic background re-render/recomposition frame executed after a recurring time interval.
   - Upon the re-render, the active cursor/caret position in the textarea abruptly jumped from the end of the text back to the very first character position (index 0).
   - Subsequent characters typed by the user were erroneously prepended to the beginning of the prompt text.
   - The glitch severely disrupts prompt authoring for any user interactively composing or refining instructions directly within the platform.
3. **Control Comparison:**
   - Pasting pre-composed text in a single block succeeds without triggering the caret jump immediately, confirming the defect is tied to active keystroke state reconciliation during periodic re-render frames.
