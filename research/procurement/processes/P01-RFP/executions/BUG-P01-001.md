## 1. Summary of Defect

In **Agent Lab**, when authoring or refining system instructions in the **"Configure Prompt"** modal under the **"Basic Config"** tab, the prompt textarea component intermittently recomposes or re-renders across a periodic timeframe or background polling interval. This periodic re-render unmounts or resets the internal textarea caret/selection state, abruptly jumping the cursor from its active typing position back to the first character position (index 0). For users typing prompts interactively, this causes severe input disruption and prepends subsequent keystrokes to the beginning of the prompt.

---

## 2. Reproduction Steps

1. Navigate to Agent Lab and open an agent workflow for prompt configuration.
2. Click **"Configure Prompt"** to launch the configuration dialog.
3. Ensure the **"Basic Config"** tab is selected.
4. Focus the **"System instructions"** textarea and begin typing prompt instructions continuously over a 20–30 second window rather than pasting.
5. Observe the caret behavior during active typing: upon a periodic background re-render interval, the cursor abruptly jumps to character position 0.
6. Continue typing without manual cursor intervention and observe subsequent characters being typed at the very beginning of the prompt.

---

## 3. Expected vs. Actual Behavior

- **Expected Behavior:** The "System instructions" textarea must maintain stable local component state and preserve the user's cursor/caret position across component re-renders, debounce frames, and autosave intervals while the input has active focus.
- **Actual Behavior:** The textarea component recomposes or resets its controlled state, forcibly moving the cursor to index 0, corrupting prompt text being actively authored.

## 5. Investigation Guidance for Developers

- Inspect the "Configure Prompt" modal and System Instructions textarea component in Agent Lab.
- Verify whether the textarea is an uncontrolled or controlled React component and whether external value props override DOM `selectionStart` and `selectionEnd`.
- Determine whether parent re-renders (such as word count calculations, autosave debounces, or runtime status polling) are causing the textarea sub-tree to unmount or remount.
- Implement caret position preservation across value reconciliations and ensure the textarea component is memoized against unrelated parent state updates.
